# Google Flow Reverse Proxy для SillyTavern

Этот скрипт позволяет расширению `sillyimages` в SillyTavern генерировать картинки через Google Flow с поддержкой **референсов (сохранение внешности персонажа)** и **2K-апскейла**.

Вместо тяжелых браузеров скрипт использует легкий Python-сервер и расширение для браузера (Chrome / Lemur / Yandex), которое само решает капчу и общается с серверами Google напрямую.

## 💻 ИНСТРУКЦИЯ ДЛЯ WINDOWS

### Шаг 1: Подготовка
1. Нажмите `Win + R`, введите `cmd` и нажмите `Enter`. В открывшейся консоли установите Python одной командой:
   ```cmd
   winget install -e --id Python.Python.3.14
   ```
   *(Команда сама скачает актуальную версию и правильно добавит её в систему)*
2. Скачайте этот скрипт (зеленая кнопка **Code** -> **Download ZIP** вверху страницы) и распакуйте архив.
3. Откройте распакованную папку.
4. Нажмите мышкой по адресной строке папки, сотрите путь, напишите `cmd` и нажмите `Enter`.
5. В открывшейся консоли установите нужные библиотеки:
   ```cmd
   pip install fastapi uvicorn websockets
   ```

### Шаг 2: Настройка браузера (Chrome / Edge / Яндекс)
1. Откройте браузер и перейдите на страницу расширений (в Chrome это `chrome://extensions`).
2. В правом верхнем углу включите **"Режим разработчика"** (Developer mode).
3. Нажмите **"Загрузить распакованное расширение"** (Load unpacked).
4. Выберите папку `extension`, которая находится внутри вашей папки `GoogleFlowProxy`. В списке появится расширение "Flow".

### Шаг 3: Запуск и Авторизация
1. В консоли (`cmd`) запустите прокси-сервер командой:
   ```cmd
   python main.py
   ```
2. Откройте в браузере сайт Google Labs: [https://labs.google/fx/tools/flow](https://labs.google/fx/tools/flow)
3. Залогиньтесь в свой фейковый Google-аккаунт. Как только интерфейс прогрузится, расширение автоматически поймает сессию и подключится к серверу (в консоли появится надпись `[МОСТ] Расширение подключено`).
4. **ВАЖНО**: Оставьте вкладку с Google Labs открытой в браузере, пока играете.

## 📱 ИНСТРУКЦИЯ ДЛЯ TERMUX (ANDROID)

### Шаг 1: Подготовка Termux
1. Откройте Termux и установите нужные пакеты (git и python):
   ```bash
   pkg update -y && pkg install git python -y
   ```
2. Скачайте скрипт с GitHub и перейдите в его папку:
   ```bash
   git clone https://github.com/ann22cadis/GoogleFlowProxy.git
   cd GoogleFlowProxy
   ```
3. Установите библиотеки:
   ```bash
   pip install fastapi uvicorn websockets
   ```

### Шаг 2: Настройка браузера
1. Скачайте мобильный браузер с поддержкой расширений, например **Lemur Browser**, **Yandex Browser** или **Mises Browser**.
2. В браузере откройте `chrome://extensions` и включите "Режим разработчика".
3. Загрузите папку `extension` (распакованное расширение).
4. Запустите в Termux скрипт `./setup.sh` (или `python main.py`).
5. В браузере откройте вкладку Google Labs, залогиньтесь. В Termux появится `[МОСТ] Расширение подключено`.
6. Дальше можно переключиться на вкладку SillyTavern — держать вкладку Labs открытой больше не обязательно.

### Шаг 3: ОБЯЗАТЕЛЬНЫЕ настройки Android

Без этих трёх пунктов прокси будет отваливаться — система просто убивает всё в фоне.

1. **Wake lock для Termux.** Берётся вручную, одной командой:
   ```bash
   termux-wake-lock
   ```
   В шторке у Termux появится `wake lock held` — так и должно быть.
   Снять, когда закончили: `termux-wake-unlock` (или кнопка **Release wakelock**
   в том же уведомлении). Пока сервер занимает сессию, команду туда не ввести —
   нужен `Ctrl+C` или новая сессия.

2. **Отключите оптимизацию батареи** для **Termux** и для **браузера**:
   `Настройки → Приложения → [приложение] → Батарея → Без ограничений`.
   На Xiaomi/Huawei/Samsung это ещё и «Автозапуск» + «Не ограничивать в фоне».

3. **Закрепите вкладки в списке недавних** (кнопка «замок» в меню приложения),
   чтобы система не выгружала браузер при нехватке памяти.

### Как это работает на телефоне

Android убивает Service Worker расширения каждый раз, когда вы уходите из
браузера. Раньше вместе с ним умирал WebSocket и все запросы терялись.
Теперь связь устроена иначе:

- **Очередь задач на сервере.** Запрос из SillyTavern не падает с ошибкой,
  если расширение спит: он ждёт до 40 секунд, пока браузер проснётся.
  Если расширение умерло, не успев взять задачу, она выдаётся заново.
- **Скрытый iframe Google Flow во вкладке SillyTavern.** Токен reCAPTCHA умеет
  выдавать любой фрейм с origin `labs.google`, а вкладка SillyTavern открыта всё
  время игры — в отличие от отдельной вкладки Labs, которую система выгружает
  первой.
- **Неслышимый звук (30 Гц).** Вкладка, которая проигрывает звук, получает
  медиа-сессию, и Android не имеет права её заморозить. Частота ниже того,
  что физически может воспроизвести динамик телефона.

**Как проверить, что защита работает.** Опустите шторку уведомлений: там
должен висеть плеер **Flow Proxy — keepalive** и строчка Termux
`wake lock held`. Если плеера нет — коснитесь вкладки SillyTavern один раз
(браузер не запускает звук без единственного касания).

**Как выключить звук.** Кнопкой паузы в том же плеере в шторке — попап
расширения на телефоне открыть почти невозможно, поэтому тумблер вынесен
туда. Выбор запоминается. На компьютере то же самое делает кнопка
**Audio: on/off** в попапе расширения.

### Если всё равно отваливается

| Симптом | Что делать |
|---|---|
| `Расширение не подключено` | Проверьте, что Termux жив и `termux-wake-lock` взят |
| `Google не принял токен reCAPTCHA` | Откройте обычную вкладку labs.google/fx/tools/flow и убедитесь, что залогинены |
| `Не удалось получить токен reCAPTCHA` | До Google запрос не дошёл: вкладка Labs спит. Разбудите её или см. раздел про Android выше |
| `Подозрительная активность (UNUSUAL_ACTIVITY)` | Это **не** капча и не авторизация. Google не доверяет IP или браузеру: смените сервер VPN (или выключите VPN), подождите 10–15 минут, генерируйте реже. Chrome/Lemur ловят эту ошибку заметно реже, чем Edge, Yandex и старый Kiwi |
| Всё встало после долгого простоя | Откройте попап расширения → кнопка обновления токена |
| Нет плеера в шторке | Коснитесь вкладки SillyTavern — звук стартует после первого касания |

## 🔗 НАСТРОЙКА SILLYTAVERN (sillyimages)

1. Откройте SillyTavern -> Настройки расширений (Extensions) -> **Генерация картинок**.
2. Введите настройки:
   - **Тип API:** `Gemini (nano-banana)`
   - **URL эндпоинта:** `http://127.0.0.1:8001`
   - **Модель:**
     - `Nano Banana 2 Lite`
     - `Nano Banana 2`
     - `Nano Banana Pro`
   - **Размер изображения:** `2K` (по желанию, включит авто-апскейл)
   - **API ключ:** `12345` (любой текст)
